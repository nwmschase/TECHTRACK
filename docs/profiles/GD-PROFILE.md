# Guided Diagnostics: what it is
Version 2.0 (descriptive statement, 2026-10-23). Chase ordered every GD profile rule removed on 2026-10-23 at 8:34 AM; the v1.2 text is preserved in `drafts/REMOVED-RULES-2026-10-23/docs__profiles__GD-PROFILE.md.md` and in git tag `pre-rule-removal-2026-10-23`.

Guided Diagnostics is a chat for an RV or trailer repair tech. The tech names the category and model and describes the complaint. Grok works with the tech toward the right diagnosis and repair for that exact unit, using the shop library first (the unit's own maker manual) and the internet when it helps. The session is recorded as state (readings in the tech's words, the pending test, the cause, the repair, the pages cited), and the state builds the warranty story. A past session can be reopened and continued from history.

How Grok is told how TechTrack works: `gd_primer.md` in the code, nothing else.
