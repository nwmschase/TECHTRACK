# PDF Builder (Bay Procedure): what it is
Version 2.0 (descriptive statement, 2026-10-23). Chase ordered every PDF profile rule removed on 2026-10-23 at 8:34 AM; the v1.5 text is preserved in `drafts/REMOVED-RULES-2026-10-23/docs__profiles__PDF-PROFILE.md.md` and in git tag `pre-rule-removal-2026-10-23`.

The Bay procedure PDF is a printable repair sheet for one unit and concern. It is built by code (`bay_procedure.py`, `manual_figures.py`) from library pages and their figures: a header with the concern, model and primary source; a diagnosis flowchart; the checks and repair steps; and the sources. No Grok call is part of building it. How the sheet is laid out is a rendering matter that lives in that code.
