# Bay procedure PDF — standing standard (Chase 2026-09-19)

**Purpose:** Every bay PDF TechTrack generates must meet this bar — not only the FCR / FACR / Firefly rebuilds. Lessons from rejected drafts are permanent product rules.

## What a bay PDF is
A printable service-bay procedure from indexed library material for a customer concern. Replaces Diagnostic Jobs tip-cards. Quality bar = Leader gold FCR10 bay write-up.

## Length
- Short path (e.g. Firefly CAN prove) → short complete sheet is OK.
- Appliance / multi-branch paths (FCR ice, FACR freeze, most seeds) → **full A→Z**, not a hint PDF.

## Full A→Z (required on long sheets)
1. Customer concern
2. What the pattern means (complete service sentences)
3. **Readable** visual flowchart — OEM-style yes/no boxes/diamonds a tech finger-walks (not condensed bot ASCII)
4. Ordered bay steps with **continued next steps after every check** (pass/fail → next branch or end)
5. **Needed manual content ON the page** (thresholds, how to test, what good/bad means) — never “open the SM / see the manual”
6. Readable library figures
7. Lands at a **confirmed fix / correction** so the tech is ready for warranty story (Concern → Cause → Correction)
8. Component **names** in body; part numbers only in Sources when truly needed

## Language bans
- No TechTrack **program / coach logic-reinforcement** do-nots aimed at the model (fuse/12V anti-path chatter on ice sheets, etc.)
- Exception: **Firefly-specific** tech-facing do-nots Chase kept (rubber-boot stay; don’t condemn controller while Auto works; don’t swap for Firefly blame; don’t push USB until Manual holds with Firefly CAN out)
- Ban jargon: “wired coach CAN,” “network plugs,” “power looks sane”
- Prefer **holds** / **still dumps home** — never “stays open”

## Firefly / Level Up locked voice
- Diagnose Firefly/OneControl **CAN** before a Level Up controller fault path (when Auto works + Manual dumps)
- Two ports labeled **CAN**: rubber-boot terminator stays; Firefly/OneControl CAN cable out only; locate on controller when figure exists
- Power: back-probe labeled **POWER CONNECTOR**, Red vs Green, solid 12V+, note Yellow
- Holds with Firefly CAN out → Firefly USB contact 574-825-4600 / interim; still dumps → Firefly ruled out, Level Up path remains
